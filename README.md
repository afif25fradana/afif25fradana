# afif25fradana

I build tools for my own use, documented so others can understand them. Based in Solo, Indonesia.

## What I'm building

<img src="https://media.tenor.com/6GnLkqlGMUgAAAAC/rover-male-rover.gif" alt="Rover" width="190" align="right" />

Personal utilities, homelab scripts, and AI experiments. I lean on AI to move faster, but I only push code I run and live with myself.

### Featured
- **[AksaraSight](https://github.com/afif25fradana/AksaraSight)** — Offline desktop OCR and CLI powered by GLM-OCR and llama.cpp.
- **[Finance-Tracker](https://github.com/afif25fradana/Finance-Tracker)** — Offline Android expense tracker with exact Rupiah ledger math and zero network permissions.
- **[Media-Dex](https://github.com/afif25fradana/Media-Dex)** — Zero-build personal media catalog with live Last.fm scrobble playback.
- **[Project-Nyx](https://github.com/afif25fradana/Project-Nyx)** — Experimental voice AI sandbox on Windows 11 running under a 2.6 GB VRAM ceiling.

### Side Tools & Dotfiles
- **[dns-bench](https://github.com/afif25fradana/dns-bench)** — PowerShell DNS latency and jitter benchmark for Windows.
- **[everyday-agy](https://github.com/afif25fradana/everyday-agy)** — Personal dotfiles, AST security guardrails, and workflow skills for Google Antigravity.
- **[felis-shell](https://github.com/afif25fradana/felis-shell)** — Modular Bash setup for WSL2 and Linux with a git-aware prompt.
- **[QoL-Bat-Scripts](https://github.com/afif25fradana/QoL-Bat-Scripts)** — Small Windows batch and PowerShell utilities for quick file organizing and screenshot renaming.
- **[taste-skill](https://github.com/afif25fradana/taste-skill)** — Experimental Antigravity skill for curated web typography and contrast checks (retired in everyday-agy in favor of impeccable).
- **[Serene-Glass-Tabliss-Theme](https://github.com/afif25fradana/Serene-Glass-Tabliss-Theme)** — Dark frosted-glass CSS theme for the Tabliss new-tab extension.
